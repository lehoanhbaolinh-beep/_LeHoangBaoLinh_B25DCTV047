## So sánh DOM thuần (A) và React (B)

| | Phần A – DOM thuần | Phần B – React |


**Nhận xét:** DOM thuần cho thấy rõ trình duyệt hoạt động thế nào nhưng càng nhiều tính năng càng phải tự đồng bộ giao diện với dữ liệu. React giảm việc đó: chỉ cần giữ state đúng, giao diện tự đúng theo. Với trang nhỏ, DOM thuần đủ và nhẹ; với giao diện nhiều thành phần dùng chung dữ liệu, React gọn và dễ bảo trì hơn.
